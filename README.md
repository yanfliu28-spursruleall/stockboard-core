# US Stock Board · 美股投研看板

一个自托管的美股投研看板：行情、估值、新闻分级、13F 机构持仓、行业景气度、盘前盘后内参，以及一个**量化因子与回测**研究页。
生成**加密的静态页面**，可放到任意静态托管（GitHub Pages / Cloudflare Pages / 内网共享盘），用口令在浏览器端解密。

> **免责声明**：仅供研究与学习，**不构成投资建议**。示例估值数字是占位数据，不是研究结论。
> 数据来自第三方（Yahoo Finance 非官方接口、SEC EDGAR、各新闻站 RSS），可用性与条款随时可能变化，使用前请自行确认合规。

## 页面模块
| 模块 | 内容 |
|---|---|
| 平台总览 | 覆盖公司、预警日报、最近重点情报 |
| 公司研究看板 | 估值三值（买点/合理价/卖点）与状态、前瞻 PE 历史分位、分析师一致预期、风险/增长要点、详情报告；手机端为卡片列表 |
| 机构持仓 | SEC 13F 最近两期对比（新进/加仓/减仓/清仓）、多机构共同持有 |
| 行业景气度 | 行业 ETF 动量 + 对 SPY 相对强弱 + 趋势 + 52 周位置 |
| 重大信息跟踪 / 市场内参 | 多源新闻去重、强度/确定性/新颖度三维打分、S/A/B/C/D 分级；盘前/盘后简报 |
| 量化因子与回测 | 手工因子（价量+基本面 PIT）/ 遗传规划 / 大模型提机制假设（可选），统一做样本内外检验、行业中性、扣成本；页面内可调参数的回测实验室 |

## 快速开始
```bash
pip install requests cryptography pandas numpy
python build.py --demo                  # 离线演示数据，生成明文页面做本地预览
python tools/serve.py                   # 本地预览 http://127.0.0.1:8765/ （读取 dist/）
```
实时数据与加密发布：
```bash
# Windows
set BOARD_PASSPHRASE=你的口令 && python build.py --skip-13f
# Linux/macOS
BOARD_PASSPHRASE=你的口令 python build.py --skip-13f
```
输出 `dist/index.html`（口令门，不含业务数据）+ `dist/app.bin`（AES-GCM 密文）。未设置口令时输出**明文**页面，仅限本地预览。
**加密页面不能双击打开**（浏览器禁止 `file://` 发起 fetch），请用 `python tools/serve.py` 或任意 HTTP 服务。

## 配置你的观察名单
- `watchlist_example.py` 是占位示例。复制为 **`watchlist_local.py`** 并填入你自己的标的、手工估值和观点；该文件已被 `.gitignore` 忽略，不会上传。
- 估值默认自动计算（历史前瞻 PE 分位 × GAAP 口径一致预期 EPS，与 DCF 交叉）；无法自动估值的标的（外国发行人等）回退到分析师目标价或你填的手工值。
- `config.py` 里的 `SEC_USER_AGENT` 请改成你自己的联系邮箱（SEC 的要求）。

## 可选：大模型研究推演
设置 `ANTHROPIC_API_KEY`（及可选的 `RESEARCH_API_BASE`、`RESEARCH_MODEL`）后，会基于已算出的结构化事实包生成“论点→证据→跟踪信号”式的风险/增长推演，并自动核对其中引用的数字是否出自事实包。未设置则自动跳过。

## 定时刷新与加密发布
- `refresh.py`：构建到临时目录 → 校验“能用口令解密 + 内容完整 + 公开页面不含明文” → 通过后才替换 `dist/`；失败保留旧版。带锁防重叠、按美股时段限频、失败计数与告警文件。
- 口令放在 `secrets/passphrase.txt`（或环境变量 `BOARD_PASSPHRASE`）；没有口令则拒绝运行，绝不输出明文。盐保存在 `secrets/salt.bin` 并保持不变（否则浏览器里保存的登录状态每次刷新都会失效）。
- Windows 任务计划：`python tools/install_schedule.py`（卸载 `--uninstall`，查看 `--status`）。其他系统可用 cron 每小时运行 `python refresh.py`。
- 发布是可选的“钩子”：把 `publish_hook.example.cmd` 复制为 `publish_hook.cmd` 并按需修改，刷新成功后自动调用。
- 日志 `logs/refresh.log`，状态 `status/last_refresh.json`；连续失败 ≥3 次生成 `logs/ALERT.txt`（不会主动通知你，需要定期看一眼）。

## 安全与局限
- 加密只防“拿到文件的人”；**口令一旦外传就无法单独收回**，只能整体换口令。需要按人授权/撤销，请改用带登录的方案。
- 页面是**静态快照**：数据最长滞后一个刷新周期；电脑关机时定时任务不会运行。
- 量化页的**幸存者偏差**：股票池是“今天的大中型股”，不含历史退市公司，会系统性高估多头回测收益；免费数据无法消除。样本只有约 10 年，遗传搜索存在多重检验问题（页面会标出噪声基线与“独立想法数”）。
- 新闻为第三方内容，对外公开或收费使用可能涉及版权与合规问题。
- 估值与一致预期来自非官方接口，随时可能失效；失效时会降级，不会让构建失败。
